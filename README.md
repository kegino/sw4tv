# SW4TV — Streaming IPTV Premium em 4K

Plataforma oficial do **SW4TV** (`sw4tv.site`), provedor de streaming IPTV de alta fidelidade com mais de 35.000 canais ao vivo, filmes, séries e esportes em 4K sem travamento.

## 🚀 Tecnologias

- **Framework**: TanStack Start + Vite + React 19
- **Estilização**: Tailwind CSS v4 + Radix UI + Lucide React
- **SEO & Otimização**: Schema.org estruturado (Product, FAQPage, HowTo, BlogPosting, OfferCatalog), OpenGraph completo, Canonical Tags dinâmicas, Sitemap XML e RSS feed nativo.
- **Performance**: Imagens WebP ultra-otimizadas com backdrop cinematográfico responsivo e paleta escura Obsidian Gold de alto contraste.

## 🛠️ Executando localmente

```sh
git clone https://github.com/kegino/sw4tv.git
cd sw4tv
pnpm install
pnpm dev
```

## 📦 Build para produção

```sh
pnpm build
```
